# 第一台原型机反馈与下一版要求

历史记录：2026-10-25（Asia/Shanghai）。当时用户要求暂停，2026-10-26 已恢复并完成 L7。以下保留需求演变，当前状态以 [HANDOFF](../HANDOFF.md) 和末尾实施结果为准，不再处于暂停状态。

## 已验证情况

- 用户报告新焊接的 ESP32-C3 + BH1750 基本验证通过，第一台原型机已完成。
- 对话中实际收到的五条读数均为 raw=113、lux=94.17；随后的感光响应由用户反馈“基本上可以了”，并非助手独立完成完整实机测试。
- 当前原型版本为 L6，保留原有 CAD、打印文件和拓竹工程，不能用下一版覆盖这台原型机的资料。

## 下一版用户要求

1. 外壳左右再宽一点，增加内部装配及焊线空间。
2. 上盖不要锁扣，只需要限位，最终使用胶水粘接。
3. 具体采用套口：上盖内侧向下伸出一圈定位裙边，下盖内壁容纳这圈裙边；不是仅用几个孤立定位柱。
4. 胶水涂好、上盖合上后，外观不能看见胶水。胶接位置必须藏在内部，不在外接缝直接涂胶。
5. 本轮只记录，明天再做，不继续修改模型或切片。

## 拟实施参数（助手提出，尚未经过用户尺寸确认或打印验证）

- 左右各增宽 2 mm（总宽增加 4 mm）；尺寸可在后续继续时调整。
- 定位裙边每侧装配间隙暂取 0.25 mm，插入深度约 1.5 mm。
- 保留外侧齐平的盖壳接缝；考虑内部隐蔽涂胶台阶/容胶槽、溢胶余量和外侧挡胶边，避免胶被挤到外观面。具体截面待设计，不能保证过量涂胶也不溢出。
- 定位裙边优先做连续一圈，USB、前挡板及内部元件附近必要时局部避让。
- 移除上盖弹性锁扣及下盖对应锁扣窗口。
- 保留四角 PCB 支撑、上盖 USB 对侧压板竖条、已验证的感光芯片相对位置及光孔对准关系。
- 加宽围绕光孔中心对称处理；不通过挪动传感器造成再次偏孔。
- 保留绿色装饰、透明图案和 FC 字母。
- 保留单颗 M3×30 内六角螺丝、塑料直接成牙无螺母方案；拓宽后必须重新检查螺丝轴向长度和有效啮合，不能简单随外壳加宽轴座跨度。
- 继续保持各个打印零件自己的底面平整，后方轴座允许伸出。

## 2026-10-26 实施结果

用户已恢复并要求修改，完成 L7 原生 Fusion 模型，另存至 `当前版本_L7_加宽套口藏胶/`。左右各增加 2 mm，上盖内套圈插入 1.5 mm、每侧间隙 0.25 mm，下盖两侧内壁藏胶槽，取消盖卡笋及对应窗口。保留参考板位置、光孔高度、四角支撑、尾端压条、配色及 M3×30 直接拧塑料转轴；加宽外壳不加宽螺丝有效跨度。

静态/PCB/插盖路径、0–90°分段转动检查通过，四个单色 STL 封闭且单连通。完整原生 F3D、STEP、STL、通用3MF和说明已归档；尚未实物验证 L7 套口配合及胶水效果。后续从 L7 继续，L6 原型不覆盖。
