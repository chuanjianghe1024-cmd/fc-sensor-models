# 文件分类导航

| 分类 | 目录 | 使用原则 |
|---|---|---|
| 芯片/模块 1 | `01_ESP32-C3-SuperMini` | 校准 STL 用于装配，原始下载网格仅追溯 |
| 芯片/模块 2 | `02_BH1750-GY302光照模块` | STEP/STL 为尺寸参考，照片与 dimensions.json 说明估算范围 |
| 上一版原型 | `03_FC传感器外壳/当前版本_L6_单件平底` | 已有用户实物反馈，不覆盖 |
| 当前外壳 | `03_FC传感器外壳/当前版本_L7_加宽套口藏胶` | F3D 是继续编辑入口；print-files 为发布打印件 |
| 设计依据 | `docs/原型反馈与L7要求.md`、`docs/装配参考照片` | 历史需求和实物方向依据 |
| 完整性/迁移 | `docs/模型文件校验.json`、`docs/清理记录.md` | SHA256 与旧资料恢复位置 |
| 临时输出 | `generated/`（Git 忽略） | 重建检查通过后再选择正式发布文件 |

每版 F3D、print-files、README 和检查报告放在同一版本目录。不要将同一零件的 color/single 同时导入；彩色模型保持各部件原位。STL 无可靠单位元数据，导入时采用 mm。

新增模块可新建编号目录并补 README，记录实测尺寸、估算参数、坐标原点、首选模型和来源。不要把推算尺寸写成实测。

新会话从 [HANDOFF](../HANDOFF.md) 进入；不要先翻恢复备份或过时脚本。
