# 文件与格式

| 目录 | 内容 |
|---|---|
| `01_ESP32-C3-SuperMini` | C3 校准 STL、原始参考网格与尺寸记录 |
| `02_BH1750-GY302光照模块` | BH1750 STEP/STL、实物照片与尺寸参数 |
| `03_FC传感器外壳` | 按版本组织的装配模型、打印文件和检查报告 |
| `docs/装配参考照片` | 模块叠放、引线和安装方向参考 |
| `docs/模型文件校验.json` | 关键模型和图片的 SHA-256 |
| `generated/` | 不纳入版本管理的临时输出 |

## 格式选择

- **F3D**：Fusion 原生装配与特征编辑。
- **STEP**：实体交换，适合其他 CAD 软件或支持 STEP 的切片器。
- **STL**：单色三角网格，按毫米导入。
- **3MF**：模型及部件关系；通用模型包不含完整打印机配置。

`single` 是合并单色版，`color` 是分色部件版。同一零件选择一种即可。分色部件应作为同一对象导入，保持相对位置。

L6 的 `L6_Complete_Set_Bambu.3mf` 为拓竹工程；其他 3MF 是否包含切片配置，以对应版本说明为准。
