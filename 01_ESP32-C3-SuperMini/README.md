# ESP32-C3 SuperMini

首选 [校准 STL](校准模型与脚本/C3-SuperMini-calibrated-mm.stl)，原始网格位于 `原始下载模型`，脚本和校准记录位于 `校准模型与脚本`。

PCB 22.5×17.8 mm，含 USB 长 23.5 mm；USB 参考外形 8.8×3.1 mm。模块总包络约 23.5×17.8×4.1 mm。PCB 厚 1 mm 沿用参考，并非用户实测；小元件外形为近似。

当前没有独立 C3 原生实体 STEP/Fusion 特征模型。组合焊接后的飞线和焊点不包含在此参考包络里。再生成脚本使用仓库相对路径，需 numpy/trimesh；优先直接复用已校准文件。
