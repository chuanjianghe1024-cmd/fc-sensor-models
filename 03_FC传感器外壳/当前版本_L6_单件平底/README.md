# L6：单个零件底面齐平

2026-10-25，基于 L5，在运行中的 Autodesk Fusion 原生 API 中修改。

用户确认：只要求每个零件的贴板底面平整，后方轴座允许伸出；不要求把轴座全部藏进长方体。

## 改动

- 底壳和固定轴座统一最低面 Z=-11.4 mm，消除原来向下突出 4.2 mm 的轴座。主底板不再被轴座架高。
- 轴心从 Z=-10.6 上移到 -8.6 mm，活动脚板本身不抬高。
- 活动轴柱改成有平底实体支座的连续轴梁，长 20.1 mm，顶部圆冠直径 5.4 mm，圆孔 3.4 mm，圆冠径向最薄壁约 1 mm。原来的圆柱直径 8.8 mm；截面缩窄用于避让 USB，并不是把旧柱简单平移。
- 活动轴柱支座一直连到腿底面 Z=-15.6 mm，不再悬空起印。保留 3M 凹槽、H 形开口和绿色边缘分色。
- 增加 90° 止挡，限制继续翻转进入 USB 插头区域；设计使用范围 0–90°。
- 每台仍使用一颗 M3×30 内六角圆柱头螺丝，通孔 3.4 mm，另一端塑料盲孔 2.7 mm，无螺母。直接成牙和夹紧力仍需试装。
- PCB 四角支撑、上盖竖条和卡扣、光孔及透明 FC 图案沿用 L5。上盖和前钩不需要重新打印。

## 文件

- `FCS-L6-individual-flat-bottoms.f3d`：装配视图，含保留但隐藏的 L5 旧零件以及新 L6 零件；不要把旧件重新打开一起导出。
- `FCS-L6-flat-parts-print-view.f3d`：只显示已摆平并分开的底壳和脚，其他组件仍保留但隐藏。
- `print-files/L6_Base_Flat.step` / `.stl`：单色底壳，毫米，最低点 Z=0。
- `print-files/L6_Leg_Flat.step` / `.stl`：单色腿，毫米，最低点 Z=0。
- `print-files/L6_Leg_Colors.step` / `.3mf`：腿的分色实体；导入拓竹后核对材料映射。
- 原生 `.3mf` 是几何文件，不是已配置或已切片的拓竹项目。

## 检查结果与打印边界

Fusion：装配实体和 PCB 干涉为零，0–90° 每 3° 采样无干涉，无特征报错。90° 以上与止挡发生预期碰撞，不能强行继续打开。USB 按 12×6 mm 的假定塑料头包络检查，仍未实际测量用户线缆塑料头。

导出 STL：两个零件均闭合、法向一致、各为一个连通体，最低点均 Z=0。底壳平面贴板面积约 1090.64 mm²；腿约 571.24 mm²。没有比主贴板面更低的轴座凸起。

本轮没有重新在拓竹切片或发送打印。平底消除了整个底板被架高的问题，不等于所有内部孔顶、止挡和 3M 凹槽都自动无需支撑；应检查孔顶和凹槽桥接层。先用单色试装，确认塑料成牙、轴冠强度和止挡效果。
